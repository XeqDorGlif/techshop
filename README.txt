# 🛒 TechShop — Интернет-магазин на Node.js

Простой интернет-магазин с корзиной, регистрацией пользователей, сохранением корзины в базе данных и админ-панелью для управления товарами.

---

## 🚀 Как запустить сайт на компьютере

### Шаг 1. Установи Node.js

1. Зайди на официальный сайт: https://nodejs.org/
2. Скачай версию **LTS** (рекомендуемую).
3. Запусти установщик и жми «Далее» до конца (все настройки по умолчанию подходят).
4. Проверь, что установка прошла успешно. Открой командную строку:
   - Нажми `Win + R`
   - Введи `cmd` и нажми Enter
   - Введи команду:
- Если появилась версия (например, `v18.17.0`), значит всё установлено правильно.

---

### Шаг 2. Скачай проект

У тебя есть два варианта:

**Вариант А. Через Git (если установлен):**
git clone https://github.com/XeqDorGlif/techshop.git

**Вариант Б. Без Git:**
1. Зайди на страницу репозитория: https://github.com/XeqDorGlif/techshop
2. Нажми зеленую кнопку **Code** → **Download ZIP**.
3. Распакуй архив в любую папку (например, на Рабочий стол).

---

### Шаг 3. Перейди в папку с проектом

Открой командную строку и перейди в папку, где лежит проект:
cd путь/к/папке/techshop

> 💡 **Подсказка:** можно не писать путь вручную. Открой папку в проводнике, нажми на адресную строку сверху, введи `cmd` и нажми Enter — командная строка откроется сразу в этой папке.

---

### Шаг 4. Установи зависимости

В командной строке (внутри папки проекта) выполни:


Подожди 1–2 минуты, пока скачаются все библиотеки.

> ⚠️ **Если выскочит ошибка `ECONNRESET` или таймаут:** это проблема с сетью. Смени зеркало npm на российское:
> ```
> npm config set registry https://registry.npmmirror.com
> ```
> И снова выполни:
> ```
> npm install
> ```

---

### Шаг 5. Запусти сервер

В той же командной строке выполни:
node server.js


**Важно:** не закрывай это окно командной строки! Пока оно открыто — сервер работает. Если закроешь — сайт перестанет открываться.

---

### Шаг 6. Открой сайт в браузере

В адресной строке любого браузера (Chrome, Firefox, Edge) введи:
http://localhost:3000

**Готово!** Сайт запущен. 🎉

При первом запуске автоматически создадутся:
- База данных `shop.db`
- Папка `public/uploads/` для загруженных картинок
- Аккаунт администратора

---

## 🔑 Вход в админ-панель

После запуска сайта войди под учетной записью администратора:

- **Логин:** `admin`
- **Пароль:** `admin123`

После входа в шапке сайта появится кнопка **«⚙ Админка»**, где можно:
- ➕ Добавлять товары (через URL картинки или загрузку файла)
- ✏️ Редактировать существующие товары
- 🗑 Удалять товары (с подтверждением)

---

## ❗ Если что-то не работает

| Проблема | Решение |
| :--- | :--- |
| `Cannot find module 'express'` | Выполни `npm install` в папке проекта |
| `EADDRINUSE: address already in use :::3000` | Закрой старое окно с сервером или перезапусти компьютер |
| Страница показывает код (`<% %>` или `{{ }}`) | Ты открыл файл `.ejs` напрямую в браузере. Открой строго `http://localhost:3000` |
| `ERR_TOO_MANY_REDIRECTS` | Очисти cookie в браузере и перезапусти сервер |
| Сайт не открывается | Убедись, что окно с `node server.js` открыто и не закрыто |
| Ошибка сети при `npm install` | Смени зеркало: `npm config set registry https://registry.npmmirror.com` |
