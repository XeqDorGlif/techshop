## ✨ Возможности

### Для покупателей:
- 🛍 **Каталог товаров** — просмотр всех доступных товаров с картинками, описанием и ценами.
- 👤 **Регистрация и авторизация** — создание аккаунта с безопасным хешированием паролей (PBKDF2).
- 🛒 **Корзина** — добавление товаров, изменение количества поштучно (кнопки `+` / `−`), удаление товаров.
- 💾 **Сохранение корзины** — корзина привязана к аккаунту пользователя и сохраняется в базе данных между сессиями.
- 📱 **Адаптивный дизайн** — сайт корректно отображается на мобильных устройствах.

### Для администратора:
- ⚙️ **Панель управления** — доступна только пользователям с правами администратора.
- ➕ **Добавление товаров** — с указанием названия, цены, описания и картинки (URL или загрузка файла).
- ✏️ **Редактирование товаров** — изменение любых характеристик существующего товара.
- 🗑 **Удаление товаров** — с автоматическим удалением из корзин всех пользователей.

## 🛠 Технологии

| Технология | Назначение |
| :--- | :--- |
| **Node.js** | Среда выполнения JavaScript на сервере |
| **Express.js** | Веб-фреймворк для маршрутизации и обработки запросов |
| **SQLite3** | Легковесная реляционная база данных (хранится в одном файле) |
| **EJS** | Шаблонизатор для генерации HTML-страниц |
| **Express-Session** | Управление сессиями пользователей |
| **Crypto** | Встроенный модуль для хеширования паролей (PBKDF2) |
| **Multer** | Middleware для загрузки файлов (картинок товаров) |
| **HTML/CSS** | Верстка и стилизация интерфейса |
